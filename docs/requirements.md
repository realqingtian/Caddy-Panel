# 需求规格说明书(PRD)

> 版本 v1.0(2026-10-10)。本文档是需求的唯一维护处,回答"做什么、验收标准是什么";怎么实现见 [M1 详细设计](./m1-design.md)。
> 需求编号规则:`FR-<模块><序号>` 功能需求,`NFR-<序号>` 非功能需求。状态:✅ M1 范围 / 🕐 后续版本。

## 1. 背景与目标

Caddy 是默认自动 HTTPS 的现代 Web 服务器/反代,但官方只有 JSON Admin API 和手写 Caddyfile 两条路,现有开源面板均不成熟(见[调研](./research-implementation-plan.md))。本项目交付一个可视化面板,让不熟悉 Caddy 配置语法的用户也能安全地管理站点、证书与配置变更。

**产品目标**:单机场景下,从零到"一个反代站点上线"不超过 3 分钟;任何配置变更可预检、可追溯、可一键回滚。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 自托管爱好者 | 在家用 N100/NAS 跑若干服务,想像 Nginx Proxy Manager 一样点几下就把 `home.example.com` 反代到本地端口 |
| 独立开发者/小团队 | 管理若干 VPS 上的 Caddy,配置改动希望有版本记录、出错能回滚,不想 SSH 手改文件 |
| 运维(未来 M3) | 多台 Caddy 集中管理 |

## 3. 功能需求 — M1

### 3.1 认证与会话(FR-10x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-101 ✅ | 用户名密码登录 | 正确凭证进入仪表盘;错误凭证提示且不签发会话;连续失败达到阈值(默认 5 次)锁定该来源一段时间(默认 1 分钟);阈值与时长支持 .env 配置并可在设置页运行时调整 |
| FR-102 ✅ | 会话保持与过期 | 未登录访问任意页面重定向登录页;JWT 过期(默认 24h,.env 可配并可在设置页调整,对新签发会话生效)后接口返回 401,前端跳登录页 |
| FR-103 ✅ | 首次启动初始化 | 首次启动自动创建管理员:密码取 `PANEL_ADMIN_PASSWORD`,未设置则随机生成并仅打印一次到日志 |
| FR-104 ✅ | 退出登录 | 退出后本地会话失效,无法再访问需登录接口 |

### 3.2 仪表盘(FR-20x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-201 ✅ | 运行状态总览 | 展示 Caddy 存活/版本、Panel 版本、站点总数(启用/停用)、最近 5 次下发结果;Caddy 不可达时有显著告警且原因可读 |
| FR-202 ✅ | 配置漂移告警 | DB 最新快照 / 磁盘 Caddyfile / Caddy 运行态不一致时,仪表盘出现告警条目并展示差异来源 |

### 3.3 站点管理(FR-30x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-301 ✅ | 新建反向代理 | 表单填写域名(多个)与上游地址(多个)后保存,从浏览器访问该域名返回上游内容;上游为 WebSocket 应用时可正常连接 |
| FR-302 ✅ | 新建静态站点 | 指定域名与根目录后保存,访问域名返回目录下 `index.html`;不存在路径返回 404 |
| FR-303 ✅ | 新建重定向 | 指定源域名与目标地址,可选永久(301/308)或临时(302);访问源域名跳转到目标 |
| FR-304 ✅ | 保存预检 | 域名格式非法、上游地址非法、域名重复等在保存时被拦截,展示 Caddy 校验错误原文,且**任何配置不生效、列表不变更** |
| FR-305 ✅ | 编辑/启停/删除站点 | 编辑后生效符合该类型 FR;停用站点立即不可访问(域名返回 404);删除后域名不再由 Caddy 服务;均需二次确认或可撤销(版本回滚) |
| FR-306 ✅ | HTTPS 自动管理 | 启用站点默认自动 HTTPS(跳转 + 证书自动签发),用户无需额外操作;表单可关闭强制跳转 |
| FR-307 ✅ | 反代进阶选项 | 支持自定义响应头、负载均衡策略(round_robin/least_conn/ip_hash/first) |

### 3.4 配置中心(FR-40x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-401 ✅ | 查看当前生效配置 | 只读展示 Caddy 当前运行 JSON(`GET /config` 透传)与渲染的 Caddyfile 全文 |
| FR-402 ✅ | 版本历史 | 每次下发(成功或失败)生成版本记录:时间、操作人、变更站点、状态;可查看任意两个版本 Caddyfile 的 diff |
| FR-403 ✅ | 一键回滚 | 回滚到任意历史成功版本后,线上配置与该版本一致,并生成一条新版本记录(回滚本身可再回滚) |
| FR-404 ✅ | 直接编辑 Caddyfile(进阶) | 高级模式可手编渲染产物:保存时先校验,失败不落盘不生效;成功则热加载并生成版本记录 |
| FR-405 ✅ | 变更零停机与失败安全 | 正常保存/回滚过程站点服务不中断;下发失败时 Caddy 保持旧配置继续服务,面板明确提示失败原因 |

### 3.5 日志(FR-50x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-501 ✅ | 在线查看日志 | 可分别查看访问日志/错误日志最近 N 行(默认 200),页面轮询自动刷新,可暂停 |
| FR-502 ✅ | 日志可定位 | 日志路径可配置;日志文件不存在时给出明确提示而非报错崩溃 |

### 3.6 系统设置(FR-60x)

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-601 ✅ | 基础设置 | 可查看/修改:Caddyfile 落盘路径、日志路径、Admin API 地址、JWT 有效期、登录锁定阈值与时长;修改后持久化(锁定参数立即生效,其余在下次操作/新签发生效) |
| FR-602 ✅ | API 文档 | 开发态提供 Swagger UI(`/swagger`),与实际接口保持同步(由 swaggo 注解生成) |
| FR-603 ✅ | 界面语言(中/英) | 设置页或 Header 一键切换中文/英文,即时生效并记住选择;antd 组件库内置文案同步切换;M1 起所有 UI 文案走 i18n,不硬编码 |
| FR-604 ✅ | 主题(亮/暗) | 支持亮色/暗色/跟随系统三态切换,即时生效并记住选择;Monaco 编辑器主题同步 |

## 4. 非功能需求

| 编号 | 需求 | 验收标准 |
|---|---|---|
| NFR-101 ✅ | 安全 — Admin API 不暴露 | Caddy Admin API 仅经 Panel 访问(unix socket 或 localhost);Panel 登录接口限速;密码 bcrypt 存储 |
| NFR-102 ✅ | 安全 — 变更安全 | 任意时刻 DB、磁盘 Caddyfile、Caddy 运行态三者一致(见设计第 3.1 节);并发操作串行化,不允许静默互相覆盖 |
| NFR-103 ✅ | 兼容 — 零侵入 | 不要求重新编译 Caddy、不要求安装插件即可运行(M1 全部功能基于官方内置能力) |
| NFR-104 ✅ | 部署 — 双形态 | Docker Compose 一条命令起完整环境;同时支持单二进制(内嵌前端)部署 |
| NFR-105 ✅ | 性能 | 面板接口 P95 < 200ms(不含 Caddy 下发);下发全流程 < 3s(常规配置) |
| NFR-106 ✅ | 可维护 | handler/service/基础设施分层;service 层单测覆盖全部失败分支;核心流程有文档对应章节 |

## 5. 后续版本需求

### M2(已细化,启动前复核优先级)

| 编号 | 需求 | 要点 |
|---|---|---|
| FR-701 🕐 | 上游健康可视化 | 展示各反代上游实时状态(`GET /reverse_proxy/upstreams`:地址/请求数/失败数);支持配置主动健康检查(路径/间隔/预期码) |
| FR-702 🕐 | 监控图表 | 内置请求量/错误率/延迟图表(读取 Caddy `/metrics`);提供一键生成 Prometheus 抓取配置 |
| FR-703 🕐 | 证书管理 | ACME 账号管理;DNS challenge 供应商配置(标注插件依赖);手动上传证书;证书到期前提醒 |
| FR-704 🕐 | 访问控制 | Basic Auth 用户管理(密码 bcrypt);IP 白/黑名单;限流规则(标注插件依赖) |
| FR-705 🕐 | 导入现有 Caddyfile | 解析已部署的 Caddyfile,可识别部分映射为领域模型,不可识别部分保留为"自定义片段"原样输出 |
| FR-706 🕐 | 备份与恢复 | 站点配置与版本历史一键导出/导入,用于迁移与灾备 |

### M3(占位,M2 后细化)

多节点 Agent 管理、Web 终端、TCP/UDP 转发(l4 插件)、RBAC 与审计增强、开放 API Token。
